# 20_daily — 계속 돌아가는 자동화

## 역할
끝나지 않고 반복 실행되는 봇·자동화. 매일 광고 성과 슬랙 알림, 정기 리포트 등.
만들기보다 유지·수정이 주 업무. 봇 1개 = 폴더 1개.

## 넣는 것 / 넣지 않는 것
- 넣음: 정기 실행되는 스크립트·봇, 그 봇의 설정과 수정 이력
- 안 넣음: 한 번 만들고 끝나는 작업 (10_project), 봇이 매일 뽑는 리포트 파일 (필요하면 봇 폴더 안 logs/)

## 구조
20_daily/봇이름/
- CLAUDE.md — 무엇을·언제·어디로 + **실행 위치(필수)**
- README.md — 실행·중지 방법, 멈췄을 때 확인 순서
- .env.example — 필요한 키 이름만 (값 없음)
- .env — 실제 키 (git 제외)
- src/ — 코드
- docs/changelog.md — 수정 이력

## 작업 규칙
1. 새 봇: 90_manual/templates/daily/ 복사 → 이름 변경 → 실행 위치(맥 cron / GitHub Actions 등) 반드시 기재.
2. 수정 전: CLAUDE.md → changelog.md 읽고 기존 의도 파악.
3. 수정 후: changelog.md에 날짜 + 무엇을 + 왜 기록.
4. 새 키 추가 시 .env.example에도 이름 추가.
5. 봇이 멈췄다는 요청: README의 확인 순서대로 점검.

## 금지
- 확인 없이 봇 실행·중지·스케줄 변경 (실제 메시지가 발송됨)
- 키를 코드·문서에 직접 쓰기
- 실행 위치 모르는 채로 수정 배포
