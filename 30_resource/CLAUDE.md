# 30_resource — 공통 참고자료

## 역할
여러 프로젝트·봇이 같이 보는 참고자료 서가. 브랜드 가이드, 시장조사, 경쟁사, 디자인 레퍼런스 등.

## 넣는 것 / 넣지 않는 것
- 넣음: 두 곳 이상에서 쓸 자료, 계속 참고할 기준 문서
- 안 넣음: 한 프로젝트 전용 자료 (그 프로젝트 docs/), Claude에게 시키는 절차 (90_manual)

## 구조
30_resource/주제/파일 — 최대 2단계
- 주제 폴더 예: brand/, market/, competitor/, design-ref/
- 주제 폴더마다 _index.md 필수: `- 파일명 — 한 줄 요약 (YYYY-MM)`
- 큰 PDF·이미지 자료는 옆에 같은 이름 .md 요약본

## 작업 규칙
1. 자료가 필요하면 해당 주제 _index.md 먼저 읽고, 필요한 파일만 연다.
2. 자료 추가 시: 맞는 주제 폴더에 넣고 _index.md 한 줄 추가. 맞는 주제 없으면 사용자에게 새 주제명 확인.
3. 큰 PDF 추가 시: 처음 한 번 요약본 .md 작성. 이후엔 요약본 우선 참고.
4. 자료가 오래됐거나 서로 충돌하면 사용자에게 알리기.

## 금지
- 파일 종류별 분류 (pdf/, image/ 폴더)
- 3단계 이상 하위 폴더
- 개인 경로(옵시디언 등) 링크 — 팀원 환경에서 깨짐. 실제 파일로 넣기
