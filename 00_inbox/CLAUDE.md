# 00_inbox — 임시 보관함

## 역할
어디 둘지 정해지지 않은 파일을 잠시 두는 곳. 다운로드, 캡처, 전달받은 자료 등.
영구 보관 장소 아님. 정리되면 비어 있는 게 정상.

## 넣는 것 / 넣지 않는 것
- 넣음: 출처·용도 미정 파일, 나중에 분류할 파일
- 안 넣음: 목적지가 분명한 파일 (바로 해당 폴더로), 완성 결과물 (98_output), 비밀값 파일

## 작업 규칙
1. "inbox 정리" 요청 시 파일별로 목적지 제안 표 작성: 파일 | 추정 내용 | 이동할 곳
   - 참고자료 → 30_resource/주제/ (+ _index.md 갱신)
   - 특정 프로젝트·봇 재료 → 해당 10_project·20_daily 폴더
   - 완성본 → 98_output/ (파일명 규칙 적용)
   - 불필요 → 삭제 후보
2. 사용자 확인 후 이동. 삭제는 반드시 개별 확인.
3. 내용 모를 파일은 열어보고 추정. 그래도 모르면 사용자에게 묻기.

## 금지
- 확인 없이 이동·삭제
- 하위 폴더 만들어 inbox 안에서 정리 (정리 = inbox 밖으로 보내는 것)
