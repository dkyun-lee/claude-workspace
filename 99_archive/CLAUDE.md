# 99_archive — 보관소

## 역할
끝난 프로젝트, 멈춘 봇을 통째로 보관. 원래 위치 구조 그대로 유지.
**사용자가 요청할 때만 연다.** 평소 검색·참고 대상 아님.

## 구조
- 99_archive/10_project/프로젝트명/
- 99_archive/20_daily/봇이름/

## 보관 절차
1. (봇이면) 실행 먼저 끄기 — cron 해제 / Actions 비활성화. 사용자 확인 후.
2. 해당 폴더 CLAUDE.md 맨 위에 `> 📦 보관: YYYY-MM-DD / 사유: ...` 추가.
3. 폴더째 이동: 10_project/이름 → 99_archive/10_project/이름
4. 사용자에게 완료 보고.

## 복원 절차
1. 99_archive/ 경로에서 원래 위치로 폴더째 이동.
2. 📦 표기 줄 삭제, progress.md·changelog.md에 복원 기록.
3. (봇이면) 실행 재개는 사용자 확인 후.

## 금지
- 요청 없이 열람·검색
- 일부 파일만 옮기기
- 봇 실행 끄기 전에 이동
