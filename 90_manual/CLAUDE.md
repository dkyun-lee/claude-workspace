# 90_manual — 반복 업무 매뉴얼 + 틀

## 역할
같은 업무를 매번 같은 방식으로 하기 위한 절차서 모음. 배포, DB 연결, 정기 보고 등.
templates/에는 새 폴더·문서를 만들 때 복사하는 틀.

## 구조
- 90_manual/업무명.md — 실제 매뉴얼 (예: netlify-deploy.md)
- templates/project/ — 새 프로젝트 틀
- templates/daily/ — 새 봇 틀
- templates/skill/ — 새 스킬 틀
- templates/manual.md — 새 매뉴얼 틀

## 작업 규칙
1. 반복 업무 요청 시: 해당 매뉴얼 있으면 절차 그대로 진행.
2. 매뉴얼 없으면: 공식 문서 보고 진행 → 성공 후 templates/manual.md 형식으로 새 매뉴얼 작성.
3. 매뉴얼대로 성공하면 이력에 날짜 + 성공 횟수 +1.
4. 절차가 틀렸거나 바뀌었으면 매뉴얼 고치고 이력에 이유 기록.
5. 성공 3회 이상 안정되면 스킬 승격 제안 (40_toolkit).
6. 틀(templates/) 수정은 사용자 확인 후. 이미 만든 폴더엔 소급 적용 안 함.

## 금지
- 매뉴얼에 키·비밀번호 (".env의 ○○ 사용"으로만 표기)
- templates/ 안에서 실제 작업
