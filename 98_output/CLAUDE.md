# 98_output — 완성 결과물

## 역할
한 번 뽑고 끝나는 완성본 저장소. 스킬·프로젝트로 만든 docx, pdf, 이미지, 광고 소재 등.

## 넣는 것 / 넣지 않는 것
- 넣음: 전달·공유용 완성 파일
- 안 넣음: 계속 고치는 작업물·코드 (10_project), 봇이 매일 뽑는 리포트 (봇 폴더 logs/)

## 규칙
1. 파일명: YYYY-MM-DD_내용.확장자 (예: 2026-10-01_견적서.docx)
2. 같은 이름 있으면 덮어쓰지 말고 _v2, _v3.
3. 결과물이 여러 파일이면 같은 이름 폴더로 묶기: 2026-10-01_광고소재/
4. 저장 후 사용자에게 경로 알려주기.

## 금지
- 기존 파일 덮어쓰기
- 작업 원본(코드, 편집 파일) 저장
